# FitEngine Web

Navbar oscura (bg-slate-950), logo 45px, tipografía Inter, color primario cian (#90ABB5) y gris metálico (#9A9D9F) del logo, botones con glow cian.

```bash
cd web
npm install
npm run dev
```

Para usar **Montserrat** en lugar de Inter: en `index.html` cambia el link de Google Fonts a Montserrat y en `tailwind.config.js` pone `fontFamily: { sans: ['Montserrat', ...] }`.
