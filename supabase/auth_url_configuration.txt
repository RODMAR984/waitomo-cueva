FitEngine — Auth / URLs (Supabase Dashboard)
============================================

Proyecto (ref en código): nfjjkvjsssgxxsuocmhj  →  https://nfjjkvjsssgxxsuocmhj.supabase.co

Verificar desde tu PC (sin pegar el token en el chat):
  1) Supabase → tu cuenta (abajo) → Access Tokens → Generate new token (empieza con sbp_).
  2) PowerShell en la raíz del repo:
       $env:SUPABASE_ACCESS_TOKEN='sbp_...'
       node scripts/supabase-mgmt-auth-config.cjs
  3) Pegá acá solo la salida (JSON o site_url / uri_allow_list), nunca el token.

---

1) Site URL (recomendado): https://app.fitengine.app

2) Redirect URLs (uri_allow_list): deben incluir lo que manda la app hoy:

   Web OAuth (PKCE): mismo origen + barra final, ej.:
     https://app.fitengine.app/
     http://localhost:8081/     (o el puerto que muestre `npm run web`)
     http://127.0.0.1:8081/

   Nativo:
     waitomo://auth/callback

   Opcional (export estático / marketing si aplica):
     https://fitengine.app/**
     https://fitengine.app/join

3) Google provider: Auth → Providers → Google (client id/secret del proyecto correcto).

Referencias: utils/fitengineUrls.js → getOAuthRedirectUriForSupabase()
